# Local Font Awesome

This is a local copy of Font Awesome 6.4.0, which is used for icons in the Dropz application. The local version ensures that the application works without an internet connection.

## Usage

The application uses the `all.min.css` file which includes all Font Awesome styles. The webfonts directory contains the font files used by the CSS.

## Updates

To update Font Awesome in the future:

1. Download the latest version from https://fontawesome.com/download
2. Extract the zip file
3. Copy the `css` and `webfonts` directories to this location
4. Update this README with the new version number
